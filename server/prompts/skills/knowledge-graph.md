# knowledge-graph
关联表示真实概念依赖，不把章节先后等同于先修，不为了连通图强造边。没有可靠依赖依据时保持节点独立。
触发：用户要求总体规划/领域地图，或明确维护知识图谱。只回答局部问题时不改图。
维护工具 maintain_graph：生成增量概念，而非覆盖已有图。每个概念包含 id（已有用原ID，新增短slug）、name、description、links（先修概念ID）、citations（本轮证据编号数组）。描述解释定义与学习价值；先修关联必须指向已有或同批概念。建议8–16个核心概念，避免把目录每一小节机械当节点。区分书中依据和通用补充；无本轮引用的新增概念不提交写入。
工具参数 {"tool":"maintain_graph","nodes":[{"id":"evaluation","name":"模型评估","description":"用独立数据估计泛化能力。","links":["data-split"],"citations":[1]}]}。
工具只产出可预览、可合并的提案；代码校验ID、引用与关联，用户点击应用才持久化。不能自行宣称已保存。
