# 原文摘录展示 · 2026-09-29

## 基线与问题

- 用户截图：来源列表保留 PDF 窄旁注的断行，正文/页眉/公式混排；公式里已有 `arg m ax` 等提取失真。
- `Tutor.tsx` 截前 240 字，`App.tsx` 搜索截前 160 字，没有围绕命中位置选段；OCR 存入的 Markdown 与公式原样输出。
- 普通导入只拼 PDF 文字项和换行，不保留空间结构。旧数据的失真不能靠排版可靠恢复。

## 本轮准则

1. 来源与搜索共用轻量渲染；列表默认三行，查看完整片段仍用现有来源入口。
2. 标题、列表、表格及完整数学标记正常渲染；不增加工具栏或大卡片。
3. 安全合并正文软换行，搜索片段围绕实际命中并高亮。
4. 保留证据原文、页码和导航锚点；展示处理不改存储。无法可靠识别的字符/公式不猜修，核对原页。

## 验收

- 内容：中文软换行、英文词间隔、Markdown/数学语法、截断边界、后部命中、残缺公式。
- 展示：来源列表不再出现长窄文字柱；窄侧栏与浮层不横向溢出；亮暗主题保持现有色系。
- 交互：搜索结果仍直接定位原页，来源预览关闭与打开原文保持有效；无新增常驻按钮。

## 结果与证据

- 来源列表：Safari 实际项目中的第 166 页摘录，原来的长窄文字柱已收为三行；书名与页码同排，完整摘录仍在原有小浮层中查看。
- 搜索：围绕命中选段并高亮；界面搜索改为整页匹配，同一来源同一页只出现一次。Safari 中“核方法”的第 28 页不再重复，点击第 153 页结果后页码正确切换到 153。
- 来源浮层：“部分字符或公式需核对原页”在正文前提示；点击“打开原文”定位到 166，返回后恢复第 163 页与原对话。未新增常驻操作。
- 320px 宽的真实组件验收页覆盖完整数学公式、短段落、列表、表格、乱码、亮暗主题。Safari 检查时发现公式受固定高度裁切，已移除固定高度并复验，保留三行限制与正常公式行高。
- 独立复核发现价格误渲染、命中被前文挤出、公式内侧空格三个边界，均已修复并回归。最终相关测试 31/31、架构检查（185 模块）及生产构建通过。构建仍有原有大包体提示。
- 可复验小样：`docs/qa/source-excerpts.html`，本地服务下打开 `/docs/qa/source-excerpts.html`。
- Safari 后台自动化期间，跨页导航的页码与章节定位已确认，但新 PDF 位图仍显示“正在绘制”；本轮没有修改 PDF 渲染器，也没有把后台位图加载算作已验证通过。

## 取舍

本轮修复展示，不重新识别整本书，也不改后端检索、引用原文或存储数据。界面搜索使用整页内容避免截断语法与重复结果。没有坐标的旧摘录无法可靠区分每一段旁注和正文；没有正确 TeX 的旧公式无法保证恢复，必须仍可核对原页。异常提示采用保守规则，不能识别所有乱码。

## 第二轮：直接显示公式并保留段落

### 新的基线与决定

第一版把来源压成三行，解决了长窄文字柱，却把标题与段落挤在一起；旧 PDF 没有 TeX 标记，单独接入数学渲染器不能恢复 OCR 公式。用户要求公式直接显示、保留必要换行，同时保持轻量。

- 完整、可辨识的公式交给现有 KaTeX；标题、段落、公式独立成行。
- 对已有正确页码与公式编号的 PDF 摘录，从本地原页裁出原式。显示分式、上下标、求和与分段函数，无需外部 OCR，也不改存储或引用锚点。
- 列表只保留短引导和一条公式；普通文字最多约 160 字。完整摘录仍用现有小浮层，宽度不增、不增加按钮。
- 以唯一编号或逐字匹配确定替换范围；重复编号不盲删正文引用。不能可靠定位的文字保留。

### 实验与修复

- 真实本地教材 163、164、166、169、179 页参与定位与渲染验证。164 页的分段函数、分式，166 页的 argmax 下标完整保留。
- Safari 在后台暂停标准 PDF 画布绘制。单幅扫描图加不可见 OCR 的页面改为直接解码本地图像，并保留原始变换、倾斜与偏移。包含可见文字、遮罩、裁切、注释、多图或未知操作时，仍交标准 display 渲染。未改主阅读器。
- 与标准 display 渲染对照，163/164/166 页像素最大误差为 1/255，平均误差小于 0.001/255。
- 独立审查及 Safari 实测发现并修复：重复编号误插图、搜索漏显示公式、公式语境错配、异步图片让浮层越界。搜索优先选取引导中包含命中词的公式，160/100 字选段不切开可渲染数学表达式。
- 同一行唯一编号能确认的纯数学 OCR 段，如 7.11 的 `0c = arg m ax LL(^C)`，由原式直接替代。跨行未知片段不按猜测删除。
- 曾尝试调用已有外部 OCR，但自动审批因未明确授权上传教材页而拒绝，未执行上传；最终方案全部使用本地文件。

### 验证结果

- 相关测试 **62/62 通过，0 跳过**；架构与直接依赖检查 **192 个模块通过**；TypeScript 与生产构建通过。保留原有大包体提示。
- Safari 实机：320px 小样亮暗两色；实际对话参考来源的 7.35、7.19、7.11；166 页小浮层中的 argmax 原式及段落；搜索“条件风险”的命中引导与 7.5 原式。弹窗关闭仍有效。
- 主 PDF 在后台自动化时仍显示“正在绘制”；这不是本次公式摘录路径的问题，未将主阅读页的后台加载计为本轮通过。

### 仍有边界

这不是整本书 OCR 重建。无编号、编号已损坏（如 7.12 被识为 `7」2`）、无法可靠匹配的跨行公式，以及正文中误识别的变量，仍可能保留损坏文字。原页公式图片已提供时，其附近无法证明归属的 OCR 残片也可能保留。不能据此宣称全部乱码已经修复。扫描原式是图像，不能当作可复制的 TeX；完整有效的文本公式则继续使用 KaTeX。
