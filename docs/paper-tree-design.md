# 纸张与拖拽

本文对应 2026-09-28 的阅读优先交互。侧栏负责项目与章节导航，主对话内部才展开纸张树。

## 只有两条规则

1. 阅读与对话：项目围绕一个 PDF，章与小节保留原目录。默认左侧提供定位，中央呈现 PDF，右侧显示同范围主对话。项目和章节都可挂多个主对话，只有其派生追问进入内部纸张树。图谱与习题在范围末尾作为卡片归档，不混成对话节点。
2. 拖拽安排空间：PDF、对话、图谱、习题都可成为主视觉、并排内容或浮窗。图谱节点与习题可引用到同级主对话；对象自身追问按需创建独立对话，关闭卡片不删除该对话。空间位置不改变归属。

## 交互约定

- 单击边栏章节定位 PDF，保留旁栏的开关状态；单击主对话装入右侧，展开箭头只展开。小节默认折叠，当前阅读或对话路径自动展开，搜索涵盖章节和主对话。侧栏不展开主对话的追问；进入主对话后，「追问 · n」入口按需显示内部子树。当前项目或章节常驻「新对话」，明确创建独立主对话；其他范围悬停或键盘聚焦时显示。
- PDF「追问」继续同范围当前对话，否则恢复最近有用户互动的主对话，分支互动归属其主对话；对象专属对话与其他章节不参与回退。空对话不覆盖已有互动，旧数据以创建时间回退；项目保留 Tutor 默认入口，章节无对话时首次提交才保存。回答中的追问仍创建内部子纸张。
- 展开的项目和章节以简短标签区分对话与学习对象，范围末尾显示知识图谱与已整理的习题文件。点击侧栏图谱或习题，在 PDF 右侧打开；习题包括工具生成的一两题小测、连续练习、教材习题和历史消息中的题目。
- 对话可按需要生成局部知识图谱或习题。同一对象在对话、归档、总览和浮卡中使用相同身份；点击标题或拖出即可使用。引用进入同级主对话的草稿，只有对象追问才显示它自己的对话。
- 图谱节点在对话内与展开后都以单击查看解释；显式「引用 / 带入对话」或拖拽才加入可移除的输入标签，不自动发送。图谱、题集和单题通过 `ObjectContext` 呈现真实类型、所属范围和可用来源；未标注的旧习题不推定生成方式，对话图谱只回链到仍存在的来源消息。
- 浮卡整条标题栏（含六点把手）统一用于自由移动，右下角用于改变大小。移动时顶中央出现主区落点，两侧出现并列落点；只有松开于停靠区才改变呈现方式。放置菜单提供键盘替代，关闭仅收起视图。
- 浮窗返回生成对话时优先复用主区、已打开旁栏或其他浮窗中的同一对话；否则以该对话替换当前浮窗，不叠加新浮窗。
- PDF、章节、对话、对象卡片拖入工作区共用中央主区、两侧并排、底部浮窗落点；所有内容标题栏常驻同一套「视图」菜单。切到浮窗移出原位置；关闭和返回入口保持可见。
- 拖拽工作区内容时，浮卡子树临时不截获落点；图谱概念引用使用独立协议，保持可操作。
- 主区内容拖向已占用的并列边缘时交换主副位置，不静默失效。主副切换保持 PDF 的阅读状态。
- 追问保留原消息、摘录、物理页码及固定范围。选区菜单为“追问 / 加书签 / 复制”，普通选区不自动创建内容。
- 回答的行内引用先预览摘录，PDF 保持原位置；点「打开原文」才跳转。「返回刚才阅读」使用按项目隔离的临时 LIFO 历史，恢复页码、页内偏移、缩放、原页/文本模式和主侧布局，不创建纸张或书签。
- 边栏的选中和并列标记定位实际打开的 PDF、章节或所属主对话；内部纸张树标记具体子纸张。展示图谱不意味着其来源 PDF 也正在显示。
- 图谱、题目、关卡共用 `LearningSurface`，主区/并列/浮卡只变外框。跨视图作答通过同一个 object ID 读取草稿和记录，不产生副本。

## 数据兼容

保留旧 ID、原始 parentId、对象快照及存储键。`projectNavigationNodes` 只负责阅读导航投影：保留 PDF 章节层级及独立主对话，把项目对话汇入既有 PDF 项目入口；内部追问和对象专属对话不进入导航。`scopeAttachments` 另外投影卡片归档，旧消息小测不需预先复制为文件。历史循环有界处理，不因为损坏边丢失内容。

内部兼容类型 `Paper`/`kind:paper` 表示旧对象视图，产品中的“纸张”指对话；这一区别集中记录于 `ARCHITECTURE.md`，不把存储术语带入 UI。
