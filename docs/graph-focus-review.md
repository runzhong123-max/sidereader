# 自由网络局部舒展：独立集成审查

2026-09-28。直接读取生产 `Graph.tsx` 与布局实现，运行坐标复现及单测；本记录不等同于 Safari 交互验收。

## 已验证边界

- `relaxLearningNeighborhood` 对真实边做双向 BFS，支持 1–3 级；点与完整标签作为一个矩形单位。
- 当前采用 **44px 绝对间距**，只在空隙不足时寻找近处空位。已经疏朗的节点不动，不按当前距离再次放大。
- 单次调用不改变焦点、外围、原数据或边；相同输入确定性输出。7 项单测通过，含循环、孤立、100 个密集长中文节点、连续30次切换焦点不膨胀。
- 两个固定外围节点原有的重叠保持不动；极密区域可向较远空位展开。这是“只调整局部”的边界。
- 生产布局依赖不含 `hovered`，悬停不移动位置。锁定后 `selected` 优先，高亮与舒展均使用同一深度的双向邻域。

## 生命周期复查

直接复查最终 `Graph.tsx`，不是只采信实现者说明：

- 同一 `viewKey` 的会话记录已保存 `focusBase`、`relaxFocus`、`localPins`，与 selected、camera 一起恢复；只读对话卡片的手动位置不写入知识数据。记录在内存中，浏览器刷新后不保留。
- 概念 ID、名称、links、持久化坐标共同形成 `geometrySignature`。挂载时只恢复签名相同的快照；挂载期间签名改变则清空快照。已覆盖“关闭期间在另一视图改名或改关系、再打开”这一原先遗漏的路径。
- 连续切换焦点从当下显示坐标取快照，焦点与外围保持当下位置；改变关联层数复用该基线，不以每次舒展结果再乘比例。
- 成功的网络内拖动清空关注、快照和临时覆盖，把新坐标交给基础布局；取消或拖出引用恢复手势前位置。切换布局、调整间距与恢复自动布局也清空旧关注。
- 自由网络的搜索居中使用整个画布，不再为未打开的详情区预留横向空间。

## 保留的取舍与边界

1. **手动拖动不等于局部舒展。** 拖动松手后未固定节点重新参与基础力布局；8节点链仅把n0移20×20，n2/n3可随模拟移动89.71/81.49世界单位。当前将此作为自由网络的重排行为保留，不能宣称“所有操作外围都不动”。已固定位置保留，冲突固定位置无法同时保证文字不重叠。
2. 44 是图谱世界坐标中的绝对空隙，不是每种缩放下的44屏幕像素。极密区域可能需移动到远处；固定外围之间已有的重叠不在局部舒展修复范围内。
3. 会话视图按 `viewKey` 保存，不等于同一图谱在所有入口共享同一个镜头；内嵌卡片与展开的对象可以各有视图。原始知识没有变化时恢复探索状态，知识几何变化时重新布局优先于保留旧快照。

## Safari 最终交互验收

- 悬停只高亮、不改坐标、不改相机；锁定后的1/2/3级与实际舒展集合相同。
- A→B→C连续探索，焦点不逃离指针，不累计拉远；取消恢复明确的全局基线。
- 拖外围、拖焦点、拖已舒展点，松开/取消/拖出引用均不遗留覆盖；实测并记录手动拖动后的网络重排是否可接受。
- 缩放后调整层数不强行缩放；窄窗详情进入与退出不改变锁定语义。
- 关闭/重新打开图谱、切主视图/浮窗、切明暗后核对所见位置与关注状态一致。
- 真实章节与密集长标签例均复验；单位几何通过不代表使用体验通过。
