# 学习对象与对象视图

当前统一术语与依赖边界见 [统一模型](../ARCHITECTURE.md)。底部早期验收为历史记录，不代表当前 PDF 渲染或导航实现。

## 使用

- 普通代码块、pseudocode/ascii围栏、独立公式和Markdown表格自动成为可打开对象。绘图、题目、轨迹与概念卡使用经过校验的 `sidereader-object` JSON 围栏，契约见 `server/prompts/objects.md`。
- 图支持折线、散点、柱形，SVG显示，可复制SVG和展开原始数据。数据来源与“示例/实测”由正文注明。当前不执行生成的 Python 或 JavaScript，不是 Matplotlib 内核。
- 对象展开按钮打开浮窗，可左右停靠。消息下的“从这里追问”引用选区或整条回答，在所属对话内创建追问。检索结果和来源片段可打开对象视图。
- 对象视图保存来源消息、对象快照与检索资料；打开它不创建对话。同一对象重复打开复用身份，关闭只收起视图。项目导航只展示资料、章节及独立对话，对象在原消息或学习对象架重新打开。纸张树仅展示某段独立对话内部的追问关系。
- 所有记录沿用项目的 IndexedDB 保存。旧项目无需破坏性迁移，缺省 papers/attempts 按空数组处理。不同浏览器使用各自本机存储。

## 题目与上下文

选择/判断题用结构化参考答案做确定性判题；简答先记录原始作答，由学习者明确自评或继续向Tutor讨论。提交前界面不显示解析；这是学习练习，不是防作弊考试环境。

每次提交持久化：对象ID、题干、作答原文/选项、结果、是否已参考提示或解析、反馈与时间。跳过、未答、答错、答对、待讨论、自评、查看提示分别处理。原题重做保留记录，不覆盖第一次尝试。已有练习文件的提交也进入相同记录。

下一轮模型请求的动态上下文包含当前对话的引用对象和最近12条学习记录；检索查询规划也看到有界的纸张与近期记录。完整记录仍在本机，不把一次答对、自评或提示后答对推断成稳定掌握。静态system前缀不随作答变化。这里只是SideReader学习上下文，没有搬运LearnFlow五核数据库或长期画像。

## 参考

只读参考了本机 LearnFlow 的 `frontend/src/paper-workbench.ts` 和 `frontend/src/main.tsx`：父纸张、来源消息、对象投影、重复打开复用、关闭与持久化分离。未修改 LearnFlow。

## 对计算机阅读的扩展

本轮除代码、伪代码、ASCII图、图、表、公式与题目外，加入：

- 执行轨迹：手动切换步骤，展示变量与判断变化。
- 概念卡：定义、成立前提、最小例子及反例。
- 原文片段与检索结果：核对推理依据。

后续值得做的专门对象是代码差异（修复前后）、测试用例（输入/预期/实际）和张量形状（每层维度变化）。它们可沿用这套身份、纸张和上下文协议，当前尚无专用渲染器。

## 验证记录

Safari实机：实际模型生成八种对象；公式、代码、表和折线图可见；对话内错误提交→打开题目纸张→Tutor引用具体错误答案；提示后正确提交被标为已辅助；从纸张回答继续创建子纸张；刷新后题目作答及分支保留。

Safari PDF：验证原页、下一页、阅读位置恢复和文字层。当前页及相邻页不依赖可见区域回调；绘制等待超过2.5秒时取消旧任务，用PDF.js的非动画帧打印渲染路径补画。该路径可能采用打印注释外观，当前阅读器不支持表单/注释编辑。文本提取改用标准流 reader，避免较旧Safari缺少流的异步迭代接口。兼容读取同时用于导入索引。

生产构建通过，34项自动回归通过。富文本组件加载时显示排版状态，不回显包含题目答案的原始对象JSON。

自动回归覆盖对象校验、图数据边界、隐藏答案、题目结果区分、上下文注入、纸张复用及幂等保存。模型生成内容仍需教学质量核对；对象协议保证可渲染与可定位，不保证示例代码或推导正确。
