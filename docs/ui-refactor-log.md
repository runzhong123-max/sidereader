## 基线与判断标准

- 基线：395 项代码测试、构建通过。真实项目是《机器学习》，第三章，第 69 页；保留已有资料与历史。
- 已证实的问题：目录与学习记录混在一次展开中；普通公式/代码/表格套重复卡片；跳过习题泄露答案；打开入口与空间去重不一致；窄屏返回目标不可见；浮窗间引用拖动被挡；关闭、来源和对象归属不够明确。
- 用户反馈：按钮和边框过多，视图难以预测，颜色与层级没有服务阅读。不能用构建通过代替易用性验收。
- 判据：每次操作能预测结果，正文优先，关闭/返回可见，移动不改内容归属，引用不自动发送，阅读/草稿/作答不会因换视图丢失。

## 失败路线与复验

- 只减圆角/改文案不能解决重复实例、返回错误、泄露答案，因此先修状态转换。
- Safari 的原生侧栏 HTML 拖动在实机失败；加入有移动阈值的指针拖动，沿用同一放置规则，后经实机成功。不能把 AX 点击成功算作拖动通过。
- 全屏下部分自动化坐标拖动没有触发，改为普通 Safari 窗口复验；产品同时保留视图菜单，拖动不是唯一入口。
- 独立审查发现：主视觉图谱丢章节名、窄屏导航缺 X、暗色设置有亮色分隔、图谱底部控制重叠；均已针对修复并复验。最小浮窗长标签曾仍重叠，补充连续空白区域排布和固定节点回归后，通过 Safari 刷新复验。
- 最后独立审查发现窄屏关闭浮窗可能把焦点送回离屏导航；已改为检查入口可见性再回退至可见内容区。解锁后在 Safari 390×700 视口实测“打开导航 → 图谱浮窗 → 关闭”：导航保持收起，AX 焦点为当前可见的对照区，截图与焦点一致，复验通过。
- 不为“轻量”移除焦点、输入边界和浮窗边界；不以极小字号塞进密集概念。

## 取舍与剩余未知

- 材料默认浮窗预览，长期对照再放置；窄屏不预告无法容纳的左右分栏。移动不改变归属。
- 暗色仅改变应用界面，白色扫描 PDF 保留原貌，避免原图颜色被改写。
- 现有记录中已有 ASCII 图与图谱重复回答，本轮不重写用户历史消息。未来模型是否总能生成恰当对象，仍取决于模型，未用本轮 UI 验收证明。
- PDF 的 OCR/文本层可能有错字与选区顺序偏差，本轮不改变源文档识别质量。
- 选文验收在第 69 页留下一个选文书签，管理资料可查看；未删除任何原有记录。测试概念/选文草稿均已清除。
- 真实学生是否能首次无指导完成任务，仍需用户使用反馈或独立学生测试；现有证据证明操作和显示正确，不能宣称已测得学习效率提升。
- 本轮实现、独立审查与上述 Safari 验收均完成；已退出响应式验收模式，恢复第 69 页 PDF 与已有对话并排，无测试引用草稿。
