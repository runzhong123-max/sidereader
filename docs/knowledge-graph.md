# 知识图谱交互

图谱帮助学生从主干建立方向，再查看局部和交叉联系。章节、项目与对话内卡片使用同一个 `Graph`，切换展示方式不改写知识或增删真实关系。

## 三种展开方式

| 方式 | 用途与实际规则 |
| --- | --- |
| 核心展开（默认） | 从显示起点看主干。先显示各部分的起点及最多5个直接分支，再按节点展开；跨分支真实关系以虚线区分。可展开全部、收起主干或更换起点。 |
| 分层关系 | 教材图按先修关系从左到右组织，循环内不排先后；对话关联图按距起点的关联距离分层，不解释成先修关系。 |
| 自由网络 | 查看交叉联系、自由放置概念。悬停看邻居，点击锁定关注，选择1/2/3层关联；可关闭局部舒展。 |

“核心”是展开起点，不是模型确认的唯一重点或学习顺序。多根、循环、断开的部分保留；布局不补造连接。项目与章节图的 `links` 表示当前概念的先修 ID；对话图传入 `relationKind="related"`，只表示关联，不显示先修箭头。

## 点、文字与边

文字紧靠所属圆点；布局按点、完整标签及展开控件的共同边界避碰。点与文字一起缩放，不再把标签独立推到外围、用长引线指回圆点。边在需要时绕过其他节点的文字区域。

核心与分层布局使用确定性的关系结构；自由网络使用有限次 d3-force 模拟，再处理标签矩形碰撞。布局结束后停止计算，没有持续晃动或为了排布而调用模型。分支展开只改变可见范围，保留既定坐标。

自由网络的局部舒展固定焦点和外围，仅给所选双向邻域寻找空位。点与文字共同边界之间的44世界单位间距是绝对目标；已经疏朗的区域保持位置，连续点选不会按比例越拉越远。高亮与舒展使用同一层数；锁定期间悬停其他点不替换已锁定集合。点击空白或取消关注回到基础布局。

## 常用操作

- 空白处拖动平移，滚轮围绕指针缩放；方向键平移，加减键缩放。底部百分比打开缩放菜单，可加减或恢复100%；旁边的适应窗口用于看全貌。
- 初次打开优先保持文字可读，必要时允许图谱超出窗口；超过6个节点且画布有未显示部分时出现缩略导航，可点击或用方向键定位。缩略图使用当前坐标，不是另一种布局。
- 顶部保留搜索和当前展开方式。展开方式菜单内可切换三种布局、展开主干，并按需展开“显示设置”或“图谱内容”。显示设置提供间距、来源筛选、独立概念和先修方向；图谱内容提供来源覆盖、补全与编辑入口。
- 搜索名称或说明并定位，能找到尚未展开的概念，不自动打开详情。筛选或仅看局部时，顶部直接出现“全图”返回入口。
- 探索后，搜索框左侧出现返回箭头（Alt + ←），回到上一个概念或视图，恢复当时的缩放、位置、展开和关注范围；“全图”仍用于清除范围、看全貌。平移和缩放不单独产生返回步骤，重复定位不堆积空步骤。
- 三种模式统一：单击概念锁定关注；双击、Enter或底部概念名称打开详情。只有选中概念后才显示关联层数入口，可选择1/2/3级；自由网络同时提供局部自动舒展开关。底部概念名称在窄窗简写为“详情”。窄窗口的详情覆盖图谱并提供明确返回。
- 教材图的详情按“直接先修”和“直接后续”分别列出；同一有向环内的直接邻居列为“相互关联”，不强排先后。对话图只列“关联概念”。点击关系中的概念可继续探索，再用返回箭头回到原处。
- 自由网络内拖动概念调整位置。可编辑图保存 `Concept.layout`，刷新后仍保留；只读对话卡片仅记住当前会话的位置。松手后其他未固定点会重新参与力布局，这是手动放置的取舍。恢复自动布局清除固定位置。
- 拖出概念到对话可引用；拖动卡片标题改变对象的放置方式。对话内图谱普通滚轮继续滚动对话，只有 ⌘/Ctrl + 滚轮缩放，避免卡片截住阅读。
- 按 Esc 可取消正在进行的拖动并恢复原位置；切换窗口或隐藏标签也会取消。拖动期间暂不响应滚轮，避免节点突然偏离指针。键盘执行菜单项后，焦点回到菜单按钮；进入编辑时则留在编辑处。

同一入口的相机、布局方式、展开范围、关注层数与局部位置在当前浏览器会话中恢复。概念名称、关联或持久化坐标变化会使旧局部快照失效；这避免恢复过期的标签几何。不同入口可有各自镜头，浏览器刷新不恢复会话镜头。

返回记录限于最近12步，并随同一入口在主区、并排或浮窗之间保留；窗口尺寸变化时保持所看世界坐标中心。修改图谱几何、手动固定节点、调整间距或恢复自动布局后清除旧记录；返回不是撤销编辑。编辑期间返回入口禁用，输入框中的 Alt + ← 不被图谱截获。

## 自动整理与补全

自动提取的完成记录独立于已有概念。对话产生或手工添加的节点不代表本章已提取；没有记录的范围和旧版提取会在进入时补提一次。成功和失败都会保存状态，相同资料不会在每次打开时重复调用；失败可主动重试。补全采用增量合并，保留原有描述、节点位置和关联。

非空图谱的展开方式菜单内，“图谱内容”提供“补全本章图谱 / 补全项目图谱”入口及实际参考页数、原文片段数、是否节选。请求进行时禁用重复触发，切换到其他图谱也不会同时发起请求；生成进度和错误仍直接显示。少于四个概念时提示可继续补全，不以数量强制拼凑概念或关系。

服务端每次只调用模型一次，输入含提示词和 JSON 元数据最多36000字符。按资料公平抽取至多24页、96个真实文本块，并在页内均匀选择多个位置。预算允许时保留全文，超预算时公平分配文字空间；片段之间可能重叠，覆盖统计不等于全文精读。每个节点仍需有效原文引用，教材图的 links 保持先修关系语义。

## 边界与验证

固定位置可能互相冲突；局部舒展不能移动两个固定外围点去修复其原有碰撞。极密的局部可能需要较远空位。“适应窗口”会把大图缩小，查看具体概念时应放大或搜索；它不承诺在任意窗口一次读完全部文字。

算法验证包含循环、多根、断开图、长标签、真实关系保留、确定性、输入不变、固定焦点与外围、连续点选不累计膨胀；对话卡片的 SSR 验证共用 Graph、关联语义和只读边界。源码审查及其取舍见 [局部舒展审查](graph-focus-review.md)。真实 Safari 的场景与证据见 [升级记录](graph-layout-upgrade.md)；源码和几何测试不能替代实机使用价值验收。

## 参考

- [TreePlus](https://www.microsoft.com/en-us/research/publication/treeplus-interactive-exploration-networks-enhanced-tree-layouts/)：渐进探索标签密集的网络；启发默认主干与逐步展开。
- [yWorks 标签布局](https://docs.yworks.com/yfiles-html/dguide/label_placement/)：标签作为布局空间的一部分；启发点与文字共同占位。
- [yWorks 增量布局](https://docs.yworks.com/yfiles-html/dguide/layout-incremental_layout/)：变化时保留空间方向感；启发展开不重新洗牌与局部舒展边界。
- [d3-force](https://github.com/d3/d3-force)：本项目自由网络的有限次模拟引擎。
