# SideReader

一个以项目为中心、本地运行的阅读与学习工作空间。React + TypeScript + Vite，Node / Express 提供模型与仓库接口。

## 启动

需要 Node.js 22.13+（推荐 24+）。

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。开发界面固定使用 5173 端口，API 使用 3001。

生产构建：`npm run build && npm start`，打开 http://127.0.0.1:3001 。两个地址的浏览器数据相互独立，请固定使用一个地址。

## 连接 DeepSeek

左下角「模型设置」填写 API Key，点击「保存并测试连接」。默认：

- Base URL：`https://api.deepseek.com`
- Model：`deepseek-flash`（官方文档中 DeepSeek V4.1 Flash 的 API 名称）
- OpenAI 兼容 Chat Completions；查询规划使用 JSON 输出。
- API Key 只写入 `.local/config.json`，目录权限 0700，文件权限 0600，并已被 Git 忽略。
- 也可复制 `.env.example` 为 `.env`；应用内已保存的配置优先。

DeepSeek 文档：[接入](https://api-docs.deepseek.com/) / [视觉](https://api-docs.deepseek.com/guides/vision)。默认关闭 thinking 以缩短交互等待；通用兼容服务不附带此字段。

## 阅读、对话与对象

- **默认围绕一本 PDF 学习。** 左侧是项目与章节的阅读导航，中央阅读 PDF，右侧实时问答。点击章节定位原文；项目与章节可挂多个独立主对话，点击后装入右侧。只有进入主对话后，“纸张”入口才展示它的追问子树。
- **对象归档在各自范围末尾。** 展开项目或章节，末尾以卡片显示自动知识图谱与习题文件。题目生成工具的小检测、持续练习与教材习题按来源自动归档；旧对话内的一两道题同样可回看。卡片保留原始身份、来源和作答记录，不成为纸张树节点。
- **对象也能在对话中动态产生。** Tutor 可整理当前对话的局部图谱，或用一两道题检验理解。图谱节点与习题可引用到同级主对话；每个对象的专属对话仅在实际追问时创建和显示。
- **空间由拖拽安排。** PDF、对话、图谱、习题都能成为主视觉、并排内容或浮窗。左侧章节或对话可拖到主区或两侧；对象可拖为浮动卡片。浮卡整条标题栏（含六点把手）用于自由移动，角落调整大小，顶部中央或两侧提示区用于停靠。放置菜单提供键盘替代；主侧互换保留对照内容，刷新与切换项目保留布局及阅读页码。
- **章节图谱随章节展开。** 点击章节末尾的知识图谱卡片，或聚焦章节后按 Shift+G 打开；图谱概念与习题拖进对话只添加引用，不自动发送。
- PDF 选文后就近显示“追问 / 加书签 / 复制”。追问把文字、物理页码和匹配的页面图像带入右侧同范围对话，用户可解除固定后继续跟随阅读；对话中的“从这里追问”才创建子纸张。
- 再导入一本 PDF 会为它新建阅读项目；已有多资料项目保留原文件及历史，不做破坏性迁移。
- 习题的草稿、作答与原文来源在对话、归档卡片和总览中同步，不因展示位置改变而复制。
- 顶部只在鼠标或键盘进入时显示标题和更多菜单，触屏保留入口。对话内部只按需展开纸张导航，不设置“对话 / 纸张树 / 桌面”模式切换，不再把对象入口重复铺在顶栏。树底部可添加资料及管理书签。

## 本机参考书

已根据用户提供的桌面资料建立两个项目：「AI Agent」与「机器学习」。原文件未修改。私有副本与首次启动数据保存在被 Git 忽略的 `.local/books/` 与 `.local/bootstrap.json`，不随源码提交。本机新浏览器首次进入会加载这些项目，后续编辑以该浏览器的 IndexedDB 为准。全新克隆不包含这些本机资料，需自行导入 PDF。

《深入理解 AI Agent：设计原理与工程实践》304 页、769 个文本块；周志华《机器学习》441 页、679 个文本块。书籍文本层已在本机提取。扫描版教材的原有 OCR 层可能包含数学符号误差，公式问题应结合原页图像核对。

## 当前功能

- **知识库**：导入 PDF（80 MB、600 页以内），导入公开 GitHub 仓库的 Markdown / MDX / TXT 文档（最多 24 个）。仓库只读取文件，不执行代码；私有仓库暂未提供登录流程。
- **阅读器**：选区附近提供「追问 / 加书签 / 复制」，书签保留完整摘录与页码；PDF 整本连续滚动（仅渲染视口附近页面，默认适应阅读区宽度）、精确文本选择层、Markdown 连续排版、页码跳转、缩放、目录、随滚动更新页码、Tutor 上下文与阅读位置记录。PDF 可切换「提取文本」，适合阅读 OCR 内容。
- **项目 Tutor**：参考个人目标、领域来源与检索证据给出说明和规划。领域全览补充各来源代表片段；这不是对所有仓库代码的完整分析。
- **学习 Tutor**：选中文本与当前页面进入检索上下文，多轮提问、检索路径展示、引用跳回来源页并高亮可匹配的文本片段。
- **学习对象**：维护概念及关联、个性化关卡、练习。出题工具支持选择 / 判断 / 简答；有答案的客观题确定性判分，简答提交后对照答案自评。教材摘题保留题号与已核对的原文页，当前只摘原题，不导入标准答案；作答后标为待核对。单次答对不自动完成关卡。
- **本机持久化**：领域名称、目标、来源、PDF 二进制、阅读位置、概念图谱、关卡、练习文件与最近得分保存在 IndexedDB。对话按项目和纸张保留最近 100 条消息；清理浏览器站点数据会删除学习资料。
- **示例内容**：没有本机参考书数据时才加载内置示例，不冒充已导入的外部书籍。参考书项目的图谱、关卡和题目初始为空。

## 回答与教学设计

回答支持 Markdown、代码高亮及复制、KaTeX 公式、三列以内的比较表和段内来源按钮；详细来源可展开。代码、表格、公式在自身容器滚动，不撑破当前对话纸张或并排区域。

输入框上方可选择「讲解 / 引导 / 自测」。服务器根据问题使用概念、数学、编码、项目规划或理解检查流程；这一选择是启发式路由，不是掌握程度模型。出题工具根据教学目的生成对话内的小检测或可继续作答的练习文件，题目与作答记录可在练习总览回看。

教学规则保存在 `server/prompts/`，动态的目标、选区、可见区域、概念、关卡和证据独立传入。对话保留初始用户目标和最近10条有效消息，超长内容标明省略。修改 `.md` 提示词后需重启API服务。

## 文档处理策略

1. 普通 PDF 在浏览器使用 PDF.js 提取文本，保留文档 ID、页码、文本偏移。
2. 启用扫描页识别后，少于 30 个非空白字符的页面渲染为图片，经服务端调用 DeepSeek 视觉接口转录。
3. 图表密集文档可勾选「识别所有页面中的图表与公式」。视觉转录会发送相应页面图片到配置的模型服务，并产生该服务的调用费用。
4. 阅读时跟踪可见的 PDF 文本 span 或段落，并将可见区域作为独立检索线索。图像模式可在自动、始终附带和关闭之间切换；自动模式根据问题中的图表、公式等关键词附带当前 PDF 页图像（规则判断，并非模型分类）。
5. 按 900 字符分块，700 字符步长，保留重叠与来源路径。扫描页的定位精度目前是页级，不提供 OCR 字符框；切换提取文本视图可选择转录文字。
6. GitHub 来源优先 README，随后读取较短路径下的文本学习文档；不导入全部源码或动态执行 MDX。

## 讨论范围与研究流程

项目 Tutor 处理跨资料的目标与规划；章节对话围绕本章，PDF 追问围绕保存的选区或页面。从关卡发起的对话归属项目，保留任务与关联原文。所有对话纸张都可继续问答或深度研究，规划类问题自动深入，也可手动选择；上下文由保存的范围与引用决定，查看位置不改变所属范围。

```
整库章节/文档目录（无法解析则按物理页段）
  → 项目讨论：跨章节抽样 → 研究 Agent 按缺口搜索/补读 → 检查覆盖
  → 章节/阅读追问：限定范围，选区 > 可见区域 > 当前页与邻页 → 按需补查
  → 带引用回答 + 真实研究轨迹/范围/用量
  → 维护工具校验提案 → 应用到所属知识图谱与唯一项目关卡图
```

研究 Agent 使用有界 JSON 工具协议，可调用 search、read_pages、read_section、catalog、read_skill。深度研究最多3轮工具调度加1次综合，普通问答最多2轮加1次综合；最多40个证据块，单块1800字符，总请求240秒上限。界面实时显示进展并可停止，取消会传给模型请求。深度模式不能仅凭初始章节抽样宣称研究完成。

知识图谱和关卡的专门维护规范位于 `server/prompts/skills/`。maintain_graph / maintain_path 工具验证原文引用、关联、阅读锚点和关卡依赖；提案可预览，应用时保留已有完成记录和节点布局，更新既有图谱归属；原消息保留提案与应用记录。题目与其他学习对象保留生成来源，对象架和消息入口提供访问，不增加对话纸张树中的节点。

Embedding 是可选增强：只在最多96个关键词/位置/均匀抽样候选中作语义补充，每批32块，按内容哈希复用进程内缓存；首次提问不向量化整本书。服务重启后缓存重建。语义候选不等于全库向量召回，失败保留目录与词法检索并记录提示。资料文本会发送至已配置的模型/Embedding服务。

研究范围是项目已导入的资料，不自动扩展到互联网。目录索引由代码生成且按内容哈希缓存，不对全书逐块发模型请求。界面区分索引页数、抽读页数和章节覆盖，不把抽读称为全文精读。具体设计与验证见 [研究架构](docs/agentic-research.md)。

## 验证

```bash
npm run check:architecture
npm run build
npm test
```

单元测试覆盖中英文检索、阅读锚点、空结果和融合去重。集成测试使用隔离临时目录和模拟 OpenAI 兼容服务，覆盖规划、回答、视觉识别、Embedding 缓存、密钥保密、文件权限和跨来源请求拒绝。模拟测试不代表已验证真实 DeepSeek Key 或视觉识别准确率。

`output/playwright/` 保存本地浏览器验证截图与临时 PDF，未纳入版本库。

## 代码结构

- `src/App.tsx`：内容打开、统一阅读绑定、并排与浮窗编排、引用返回。
- `src/domain/`：统一类型、对象注册表、内容解析、关系遍历和资料命令。
- `src/components/LearningSurface.tsx`：主区、并排和浮窗共用的图谱、关卡、练习、对象视图。
- `src/persistence/`：本机项目/PDF仓库、存储版本与偏好入口。
- `src/services/`：HTTP、Tutor流与PDF加载。
- `scripts/check-architecture.mjs`：依赖边界与锁文件检查。
- `src/components/PaperTree.tsx`：项目与源文件导航、主选中和对照状态。
- `src/components/ObjectShelf.tsx`、`src/paper-navigation.mjs`：学习对象架、范围筛选与可对照对象。
- `src/components/StudyWorkspace.tsx`、`src/components/FloatingObject.tsx`：双栏、浮窗移动缩放与停靠。
- `src/object-transfer.mjs`、`src/tutor-sessions.mjs`：对象拖拽协议、输入草稿与概念引用快照。
- `src/conversation-model.mjs`：独立对话归属、内部追问关系与兼容投影。
- `src/reading-scope-navigation.mjs`：项目阅读入口、章节知识图谱与习题卡片归档。
- `src/components/ConversationWorkspace.tsx`：单个对话的正文、纸张树和桌面。
- `src/paper-tree-state.mjs`：对象归属、唯一图谱、关卡与历史记录迁移。
- `src/auto-graph-state.mjs`、`src/use-automatic-graph.ts`：项目及章节图谱生成、可见范围队列与保存。
- `src/components/Reader.tsx`：PDF / Markdown 阅读器与文本选择。
- `src/components/Tutor.tsx`：双模式辅导、证据和多轮问题。
- `src/components/Graph.tsx`：知识图谱维护。
- `src/components/Questions.tsx`：题目编辑与练习工作台。
- `src/components/Modals.tsx`：导入处理、模型设置。
- `server/retrieval.mjs`：BM25、阅读上下文与排序融合。
- `server/providers.mjs`：模型、视觉与 Embedding 适配、服务端配置。
- `server/index.mjs`：API 和仓库导入。

本版本面向单人本机使用。服务绑定回环地址，没有多人登录或云同步；不要直接暴露到公网。
